# Humantalk 数字人项目概览报告

日期：2026年10月9日  
面向读者：项目汇报、业务交流及非技术人员  
项目背景：四川博览集团展会数字人项目

## 一、项目介绍

Humantalk 是一个面向展会、会议和展馆服务的数字人交互平台。项目以 OpenTalking 实时数字人框架为基础，将人工智能对话、语音识别、语音合成、数字人形象和展会业务资料连接起来，为观众提供能够听取问题、回答咨询、讲解内容和展示相关资料的数字人服务。

通俗地说，系统希望把展会中的一部分咨询和讲解服务，变成一个可以通过自然语言交流的“数字讲解员”。观众可以直接说出问题，或输入文字；系统结合当前展会的资料组织回答，再通过数字人的声音、口型和字幕呈现，并按业务需要展示展品图片、路线或登记二维码。

项目由面向观众的数字人交互端和面向工作人员的管理后台组成。交互端提供现场服务，后台负责维护展会信息、数字人形象、知识资料和服务配置，使数字人能够随着展会内容变化而更新。

## 二、项目解决的问题

展会现场的信息通常分散在展商资料、展品介绍、活动安排和场馆地图中。观众往往需要询问工作人员，或在不同页面中查找；工作人员则需要反复回答时间、地点、展品和路线等常见问题。

本项目将这些信息集中到数字人服务入口，让观众以提问的方式获取所需内容，也让运营人员能够统一维护对外介绍和常用回答。项目希望减少重复性咨询工作，帮助观众更方便地了解展会，并通过数字人形象增强现场展示的互动性。

## 三、主要使用场景

当前项目主要围绕展会和会议建设，适合在入口咨询区、服务台、展区介绍点或展位互动展示等位置使用。具体终端和网络环境需要结合部署条件配置。

| 使用场景 | 数字人可以提供的服务 |
| --- | --- |
| 展会迎宾与介绍 | 介绍展会主题、基本信息及参观内容，播放欢迎话术 |
| 展商与展品讲解 | 回答展商、产品及技术相关问题，配合展示文字和图片 |
| 活动与会议咨询 | 查询论坛、会议和活动的时间、地点及相关介绍 |
| 展馆导览 | 根据配置的场地、点位和路线资料，提供目的地说明与路线展示 |
| 常见问题解答 | 回答经过维护的官方问答，或结合展会知识库回答进一步的问题 |
| 意向登记与服务衔接 | 展示登记二维码，引导有兴趣的观众进入后续联系或服务流程 |

在更换业务资料和角色配置后，这类能力还可拓展到企业展厅、博物馆、文旅游客中心及公共服务咨询等场景。这些属于可拓展方向，本报告不将其列为本项目已经完成的行业部署。

## 四、系统如何工作

一次典型交互可以概括为：**观众提问 → 理解问题并查询资料 → 组织回答 → 合成语音和数字人画面 → 播放并展示相关信息。**

观众通过麦克风或文字输入问题。语音输入先被转换为文字，系统再判断问题涉及展会介绍、展品、活动还是导航等内容。对已经发布的官方问答，系统可以直接使用维护好的答案；对需要进一步解释的问题，则结合知识检索结果，由大模型组织回答。

回答生成后，系统将文字转换成语音，并通过数字人驱动模型生成相应的口型画面。浏览器播放声音和画面，同时显示字幕及相关资料。系统还具备唤醒、连续监听和播报中断等交互机制，用于适应现场咨询过程。

工作人员在后台维护资料、问答、形象和配置。不同展会可以绑定相应的内容与数字人资源，使同一套平台能够服务不同主题的活动。

## 五、采用的主要技术

项目将多项技术组合成完整的服务链路，各项技术承担的作用如下。

| 技术方向 | 主要技术或组件 | 在系统中的作用 |
| --- | --- | --- |
| 页面与管理后台 | React、TypeScript、Vite | 构建观众交互页面和工作人员管理页面 |
| 后端服务 | Python、FastAPI | 处理业务请求、会话管理及各类人工智能服务调用 |
| 语音识别与合成 | 讯飞等语音识别适配、Edge TTS 等语音合成适配 | 将观众语音转成文字，将回答文字转成声音 |
| 大模型对话 | OpenAI 兼容接口、DeepSeek 等服务配置 | 理解问题并组织自然语言回答 |
| 知识检索 | RAG、Dify、官方问答库 | 从展会资料中寻找回答依据，提供业务相关内容 |
| 数字人驱动 | QuickTalk 等模型及可插拔模型后端 | 使数字人画面与播报语音配合呈现 |
| 音视频与实时通信 | WebRTC、WebSocket、SSE、aiortc、FFmpeg | 传输音视频、字幕与交互状态 |
| 数据与管理 | SQLite、Excel 批量导入、账号权限和审计 | 保存运营资料，支持内容维护和后台管理 |

项目的主要工作在于把现有模型、语音服务、媒体链路与展会业务集成起来，并完成可使用的前后台。成果体现为数字人应用的工程实现和业务适配，基础模型来自所集成的模型与服务。

## 六、目前做成了什么

**形成了数字人对话链路。** 系统已经具备文字和语音输入、问题处理、回答生成、语音播报、数字人画面和字幕展示等能力，可以围绕展会内容进行互动。

**形成了展会业务服务模块。** 当前代码包含展会、展商、展品、活动、场地、点位和路线等数据管理与查询能力，并将资料展示、导航及二维码登记纳入观众交互流程。实际服务内容取决于该展会的数据维护和配置情况。

**形成了知识维护与问答机制。** 项目具备官方问答、知识库检索和未命中问题记录等能力，运营人员可以维护常见答案，并根据观众的问题补充资料。

**形成了可管理的数字人平台。** 后台包含数字人形象、声音、知识、交互配置以及账号权限等模块，并具备 Excel 资料导入能力，为更换展会内容和数字人资源提供基础。

**开展了真实服务部署与链路复测。** 仓库中的近期记录包含计算机大会场景下的服务器部署，以及语音识别、知识问答、语音合成、QuickTalk 和 WebRTC 的实际联调。项目也围绕语音交互、回答等待时间和音视频播放进行了持续优化。

当前成果可表述为：已形成面向展会的数字人交互平台及主要业务模块，并完成部分真实链路验证。不同展会的导航资料、知识内容和运行配置仍需要分别完善；现场噪声、网络条件、连续运行和多人使用效果需要结合具体场景验收。

## 七、项目价值

对观众而言，数字人提供了一个直观的咨询入口，能够通过说话或文字获取展会信息，并结合图片、字幕和路线说明理解内容。

对主办方和展商而言，系统可以承接部分重复咨询和基础讲解，统一维护对外介绍，并将产品展示与意向登记连接起来。

对运营人员而言，后台让展会资料、知识答案和数字人资源能够持续维护。项目由此具备复用基础，可以在更换业务资料、形象和配置后，继续服务其他展会或相关展示场景。

## 八、可直接用于汇报的项目简介

Humantalk 是围绕四川博览集团展会业务建设的数字人交互平台。项目基于 OpenTalking 框架，融合大模型、语音识别、语音合成、知识检索和数字人驱动技术，面向观众提供展会咨询、展品讲解、活动查询、导览及登记引导等服务，并通过管理后台维护展会资料、数字人形象和知识内容。目前已形成主要业务模块和数字人对话链路，开展了实际部署与联调，主要适用于展会、会议和展馆服务，也具备向企业展厅及文旅导览等场景拓展的基础。
