# 展会运营数据 Excel 导入

展会创建完成后，管理员可在“展会工作台 → 批量导入本届数据”一次导入运营数据和问答知识素材。导入采用“上传 → 预览校验 → 确认提交”两阶段流程，模板中未出现的记录不会被删除。导入包包含已发布的知识文档时，mock/本地开发模式无需配置 Dify 也能完成展会问答检索。

## 文件格式

- 无图片：直接上传模板生成的 `.xlsx`。
- 有图片：上传一个 ZIP，包内结构如下：

  ```text
  data.xlsx
  images/
    exhibitor-a.png
    hall-map.webp
  ```

图片支持 JPG、PNG、WebP、GIF、SVG，单张不超过 10MB，ZIP 解压后总大小不超过 100MB。Excel 中的 `image_refs` 每行填写一个 `images/` 下的文件名。

模板表头会直接标注字段属性：`【必填】` 必须填写，`【选填】` 可以留空，`【系统生成】` 由系统自动生成，`【系统填充】` 由当前展会详情自动填入；玫红色表头表示必填，青绿色表头表示选填，灰色表头表示系统生成，棕色表头表示系统填充。每个表头的批注还会提供字段说明。

## 工作表

| 工作表 | 作用 |
| --- | --- |
| 说明 / 字段说明 / 数据字典 | 导入规则、字段定义和枚举值 |
| 展商 | 展商基本资料、简介、联系人和图片 |
| 展品 | 展品资料及所属展商 |
| 场馆 | 场馆名称、地址和图片 |
| 点位 | 场馆内点位、坐标及可选展商/展品关联 |
| 路线 | 路线名称、类型、播报文本和图片 |
| 路线点位 | `route_id + point_id + sort_order`，维护路线点位顺序 |
| 活动排期 | 活动时间、地点、主讲方和状态 |
| 应急播报 | 播报内容、优先级、目标终端和生效时间 |
| 知识库 | 展会知识库名称和绑定标识 |
| 知识文档 | 可直接检索的正文、关键词、分类和发布状态 |
| 问答知识 | 标准问题、匹配关键词、官方答案和审核状态 |

## ID 与更新规则

- `id（系统自动生成；更新时可填写）`：新增记录留空，系统会自动生成；更新已有记录时填写原 ID，重复导入同一 `kind + id` 会更新原记录。
- 展商、展品、场馆、点位、路线、知识库、知识文档和问答的关系字段支持填写系统 ID，也支持填写名称、编码或展位号，系统会在预览阶段自动解析。
- 所有业务表的 `exhibition_id` 必须等于当前工作台展会 ID。
- `exhibition_id` 不需要手工填写；导入接口使用当前展会详情页的展会 ID 自动填充。若文件显式填写了其他展会 ID，预览会阻止提交。
- 展品的 `exhibitor_id`、点位的 `venue_id`、路线点位的 `route_id/point_id` 等关系会在预览阶段校验。
- 路线至少需要两个点位；省略路线的 `directions` 时，系统会根据点位自动生成基础指引。
- 路线类型为 `navigation` 或 `tour` 时会参与数字人导航；`emergency` 仅作为应急路线资料保存。
- 如果当前展会尚未配置运行参数，首次导入提交会根据路线关键词和实体名称自动创建默认数字人运行配置；已有运行配置不会被覆盖。
- “知识文档”只会检索 `published`（或 `ready/active`）状态；“问答知识”只有 `published` 状态会直接命中并播报。
- 没有 Dify 配置或本地向量库时，系统会优先使用本次导入的已发布知识文档做确定性本地检索；因此不应只导入展商/路线表而省略知识素材。

## 图片策略

| `image_mode` | 行为 |
| --- | --- |
| `keep`（默认） | 保留数据库中的原图片；忽略本行的图片附件/URL |
| `replace` | 用 `image_refs` 中的附件和 `image_urls` 中的 URL 替换原图片 |
| `clear` | 清空该记录图片 |

附件会先按 SHA-256 去重，再写入现有场景资源存储，最终只把可访问的资源 URL 写回业务记录。数据库提交失败时会回滚记录并清理本批次新建的资源文件。

## 接口

- `GET /api/v1/admin/event/exhibitions/{exhibition_id}/import-template`
- `POST /api/v1/admin/event/exhibitions/{exhibition_id}/import/preview`（multipart 字段 `file`）
- `POST /api/v1/admin/event/imports/commit`（JSON：`{"batchId":"..."}`）
- `GET /api/v1/admin/event/exhibitions/{exhibition_id}/imports`
- `GET /api/v1/admin/event/imports/{batch_id}/error-report`

导入权限码为 `event:import`，默认授予系统管理员和内容运营角色。每个预览批次会记录操作者、文件名、校验结果和提交状态，便于审计和问题追踪。
